# severinvisionary.github.io

The site root for https://severinvisionary.github.io/ — an index of the
certified-mathematics deposits, plus the two files that only work at the root of
a `github.io` host:

- `robots.txt` — a project site's `/<repo>/robots.txt` is **not** read by
  crawlers; only the host-root one is.
- `sitemap.xml` — a sitemap index pointing at `sitemap-home.xml` and the sitemap
  of every project landing page.

Add a new project here when it gets a landing page: one `<sitemap>` entry and
one card in `index.html`.
